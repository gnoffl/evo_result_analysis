# src/workflows/mutation_distance_analysis/

Compares the distribution of inter-mutation distances (consecutive differences of sorted SNP positions per gene) of the EA's real pareto-tip mutations against a random null drawn from the EA's own pooled positional usage. Input: a MutationPool JSON (from `mutation_distribution_analysis/mutation_pool.py`). Output: overlay + difference plots (full and ≤50 bp zoom) and a stats file (KS statistic/p-value, Wasserstein distance) in `results/`. `plans/` holds design/speedup notes; tests in `test/workflows/mutation_distance_analysis/`.

## mutation_distance_analysis.py  [library | script]
Real-vs-null mutation-distance analysis; imports `calculate_mutation_distances_single_gene` (analysis.mutations.analyze_mutations), `PositionSampler` (mutation_distribution_analysis.conditional_poisson), `MutationPool` (mutation_distribution_analysis.mutation_pool). Several functions (`compute_*_distances`, `_to_proportions`, `plot_difference`) are imported by `paper_plots/compose_plots_mpl.py`. CLI: `python -m workflows.mutation_distance_analysis.mutation_distance_analysis --pool <pool.json> --output-dir <dir> --name <id> [--n-per-gene 10] [--seed 42] [--format png]`.

- `compute_real_distances(pool: MutationPool) -> Counter` — per gene, sorted-position `np.diff` of the pool's real SNPs, summed into one `{distance: count}` Counter; genes with <2 SNPs skipped.
- `compute_random_distances(pool: MutationPool, n_per_gene: int, rng: np.random.Generator) -> Counter` — null: for each gene with k = `gene_stats.n_mutations` ≥ 2, draw `n_per_gene` sets of k distinct positions from the UNFILTERED pooled positions (all genes, no wildtype/source-base filtering) under the max-entropy design with inclusion prob exactly k·n_i/N (n_i = pool rows at position i, N = all rows; capped at 1); `np.diff` of each sorted set, aggregated. One `PositionSampler` cached per distinct k.
- `counter_to_array(counter: Counter) -> np.ndarray` — expand `{value: count}` to a flat sorted array (for KS / Wasserstein).
- `plot_overlay(real: dict[int, float], random_dist: dict[int, float], name: str, output_dir: str, output_format: str = "png", max_distance: Optional[int] = None, ax: Optional[plt.Axes] = None) -> None` — real proportions as bars, random as orange line; x-limit cut where real proportion < 1% of max; saves `mutation_distances_{name}_overlay[_smaller].{fmt}` only when `ax` is None. Inputs must already be proportions (private `_to_proportions`).
- `plot_difference(real: dict[int, float], random_dist: dict[int, float], name: str, output_dir: str, output_format: str = "png", max_distance: Optional[int] = None, ax: Optional[plt.Axes] = None) -> None` — bar plot of P(real) − P(random) per distance (blue ≥0, red <0); saves `..._difference[_smaller].{fmt}` only when `ax` is None.
- `run_distance_analysis(pool_path: str, output_dir: str, name: str, n_per_gene: int = 10, seed: int = 42, output_format: str = "png") -> None` — end-to-end driver: load pool, both Counters, 4 plots (full + `max_distance=50`; docstring wrongly says "≤ 200"), writes `mutation_distances_{name}_stats.txt` (ks_statistic, ks_pvalue, wasserstein_distance on expanded arrays).
- `parse_args() -> argparse.Namespace` — CLI parsing; validates pool file exists and format ∈ {png,pdf,jpg,jpeg,svg,tiff}.
